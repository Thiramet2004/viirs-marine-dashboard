🌊 VIIRS Dashboard Embedding Demo

ตัวอย่างการนำ Dashboard ไปใส่ใน Marine GIS Portal หรือเว็บไซต์อื่นๆ
ลองเปลี่ยน Tab เพื่อดูโหมดต่างๆ และดู Code ตัวอย่าง

1. Dashboard เต็มรูปแบบ แนะนำ 1200px

แสดงแผนที่ + กราฟทั้งหมด 6 รูป (เหมาะสำหรับหน้า Dashboard หลัก)

<iframe src="http://localhost:5001/embed_dashboard.html" width="100%" height="1200px" frameborder="0" style="border: 1px solid #e2e8f0; border-radius: 8px;" title="VIIRS Marine Dashboard" ></iframe>

2. เฉพาะแผนที่ (Map Only) 600px

แสดงเฉพาะ Interactive Raster Map (เหมาะสำหรับหน้า Map Viewer)

<iframe src="http://localhost:5001/embed_dashboard.html?mode=map" width="100%" height="600px" frameborder="0" title="VIIRS Satellite Map" ></iframe>

3. เฉพาะกราฟ (Charts Only) 800px

แสดงเฉพาะกราฟวิเคราะห์ทางสถิติ (เหมาะสำหรับหน้า Reports)

<iframe src="http://localhost:5001/embed_dashboard.html?mode=charts" width="100%" height="800px" frameborder="0" title="VIIRS Statistical Analysis" ></iframe>

4. Standalone Mode 1200px

ซ่อน notice bar ที่บอกให้เปิดหน้าใหม่ (เหมาะสำหรับ Full Integration)

💡 เคล็ดลับ: ใช้ ?standalone=true เมื่อต้องการให้ดูเหมือนเป็นส่วนหนึ่งของเว็บไซต์ ไม่ใช่ embed จากที่อื่น
<iframe src="http://localhost:5001/embed_dashboard.html?standalone=true" width="100%" height="1200px" frameborder="0" title="VIIRS Marine Dashboard" ></iframe>

📚 Quick Reference

โหมด URL ความสูงแนะนำ ใช้เมื่อไร
Full /embed_dashboard.html 1200px หน้า Dashboard หลัก
Map /embed_dashboard.html?mode=map 600px Map Viewer, Gallery
Charts /embed_dashboard.html?mode=charts 800px Reports, Analytics
Standalone /embed_dashboard.html?standalone=true 1200px Full Integration
🔗 URL Parameters:
• mode - เลือกโหมด: map, charts, หรือไม่ระบุ (full)
• standalone - ซ่อน notice: true หรือ false

ตัวอย่าง: ?mode=map&standalone=true
