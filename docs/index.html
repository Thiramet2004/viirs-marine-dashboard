🌊 VIIRS Marine Dashboard

ระบบติดตามสิ่งแวดล้อมทางทะเลด้วยข้อมูลดาวเทียม VIIRS
SST & Chlorophyll-a | Gulf of Thailand & Andaman Sea

⚠️ หมายเหตุสำคัญ: Dashboard แบบเต็มรูปแบบต้องรัน Flask Server เนื่องจากต้องประมวลผลข้อมูล GeoTIFF ขนาดใหญ่ (277 MB) แบบเรียลไทม์ GitHub Pages รองรับเฉพาะ Static Files เท่านั้น
📚 View on GitHub 📖 Read Documentation 🔗 Embed Guide

✨ Features

🗺️ Interactive Map

แผนที่แบบ Interactive พร้อม pixel query และ land masking

📊 6 Charts

กราฟวิเคราะห์ครบครัน Time Series, Scatter, Anomaly, Trend

🔄 Dual Views

ทั้ง Absolute และ Anomaly views สำหรับ SST & Chl-a

📅 8-Year Archive

ข้อมูล 2018-2025 (96 เดือน) พร้อม climatology baseline

🚀 Quick Start

เพื่อรัน Dashboard แบบเต็มรูปแบบ:

  1. Clone repository:
git clone https://github.com/Thiramet2004/viirs-marine-dashboard.git cd viirs-marine-dashboard
  1. Install Python dependencies:
pip3 install flask flask-cors rasterio geopandas numpy pandas
  1. Run Flask server:
python3 server.py
  1. Open in browser:
http://localhost:5001

🌐 Embedding

หลังจากรัน server แล้ว สามารถ embed ลงใน Marine GIS Portal ได้:

Dashboard เต็มรูปแบบ:

<iframe src="http://localhost:5001/embed_dashboard.html?standalone=true" width="100%" height="1200px" frameborder="0" ></iframe>

เฉพาะแผนที่:

<iframe src="http://localhost:5001/embed_dashboard.html?mode=map&standalone=true" width="100%" height="600px" frameborder="0" ></iframe>

เฉพาะกราฟ:

<iframe src="http://localhost:5001/embed_dashboard.html?mode=charts&standalone=true" width="100%" height="800px" frameborder="0" ></iframe>

📊 Data

  • Sensor: VIIRS (Suomi NPP / NOAA-20)
  • Level: L3 Monthly Composite
  • Resolution: 4 km (~0.04167°)
  • Parameters: SST (°C) & Chlorophyll-a (mg/m³)
  • Period: January 2018 - December 2025 (96 months)
  • Coverage: Gulf of Thailand & Andaman Sea
  • Files: 192 RGB GeoTIFF (277 MB total)

🔧 Technical Stack

  • Backend: Flask + rasterio + geopandas
  • Frontend: Leaflet + georaster-layer-for-leaflet + Chart.js
  • Data Format: RGB GeoTIFF (LZW compressed)
  • Coordinate System: EPSG:4326 (WGS84)
