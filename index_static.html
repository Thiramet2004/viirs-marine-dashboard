Interactive Map Demo

💡 คลิกบนแผนที่เพื่อดูค่า | เลื่อน Zoom ได้ | Demo: แสดง SST Anomaly มกราคม 2024

📚 วิธีใช้ Dashboard แบบเต็มรูปแบบ

  1. Clone repository:
    git clone https://github.com/Thiramet2004/viirs-marine-dashboard.git
  2. Install dependencies:
    pip3 install flask flask-cors rasterio geopandas
  3. Run server:
    python3 server.py
  4. Open: http://localhost:5001

🌐 Embed Code

หลังจากรัน server แล้ว ใช้ code นี้เพื่อ embed:

<!-- Dashboard เต็มรูปแบบ -->
<iframe 
  src="http://localhost:5001/embed_dashboard.html?standalone=true" 
  width="100%" 
  height="1200px" 
  frameborder="0"
></iframe>

<!-- เฉพาะแผนที่ -->
<iframe 
  src="http://localhost:5001/embed_dashboard.html?mode=map&standalone=true" 
  width="100%" 
  height="600px" 
  frameborder="0"
></iframe>
